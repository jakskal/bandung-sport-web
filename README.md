## What

A directory of sports venues in Bandung — filterable by type, budget, and area.

## Why

So people can easily find a place to work out that fits their situation and budget.

## Stack

Vite + React 19, oxlint, Prettier

## Run locally

```bash
npm install
npm run dev
```

## Roadmap

- v1: list + filter budget/area (in progress)
- v2: personalized suggestions based on user profile
